## Quick Publish (no terminal needed — 2 min)
1. Go to **https://github.com/new**
2. **Repository name:** `portfolio` (or `poojareddy24817.github.io` for a personal site)
3. Make it **Public**, check **Add a README file** OFF (important)
4. Click **Create repository**
5. Click **Add file → Upload files**
6. Drag **`index.html`** and **`N_Pooja_Reddy_Resume.pdf`** from this folder
7. **Commit changes**
8. Go to **Settings → Pages** (left sidebar)
9. Under **Source**, select **Deploy from a branch** → **Branch: main** → **/ (root)** → **Save**
10. Wait 1-2 min, refresh Settings → Pages — your link appears at the top. Tap it — it opens your portfolio directly.

## Git way (if you prefer terminal)
```bash
git remote add origin https://github.com/poojareddy24817/portfolio.git
git push -u origin main
```
Then enable Pages as in step 8-10 above.
